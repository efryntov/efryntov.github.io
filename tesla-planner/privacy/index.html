Privacy information

Tesla Shift Planner is a personal development prototype for reviewing and synchronizing one-time preconditioning schedules.

Sign-in takes place on Tesla’s website. The application does not collect your Tesla password. Tesla authorization determines which vehicle data and commands the application can access.

The static setup website serves a public key and a login callback. An authorization response may appear in the callback URL; the callback page removes that query from the visible address bar and keeps the response in page memory until the page is closed. It contains no analytics or third-party scripts and makes no additional network requests.

GitHub Pages hosts this website and may process normal request metadata, including the initial callback URL, under GitHub’s own privacy policy. Tesla processes Fleet API requests under Tesla’s policies.

The Android prototype encrypts its vehicle key and Tesla tokens using Android Keystore. Confirmed shifts, parking coordinates, diagnostic notes, and exact schedule ownership records stay in app-private storage; backups are disabled. Local setup tools store authorization tokens in private local files and never publish them to this website.

WorkJam screenshots are processed on the phone using the bundled Google ML Kit text recognizer. Images and recognized text are not sent to a screenshot-processing server. Google states that ML Kit may send API performance and usage metrics and contact Google for maintenance information; it does not send input images or recognition outputs. See Google’s ML Kit privacy terms.

Deleting local app data or setup files removes those local records, but does not delete schedules already stored on the vehicle. Clearing app data or changing phones loses the local schedule ownership receipts; the planner then treats existing vehicle schedules as external rather than guessing which it created.

You can revoke third-party access in your Tesla account and remove an application key using the vehicle’s Controls → Locks screen.
